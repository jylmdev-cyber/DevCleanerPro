# Contributing to DevCleaner Pro

First off, thank you for considering contributing to DevCleaner Pro! It's people like you that make DevCleaner Pro such a great tool for developers.

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub issues. If you find a bug, please create an issue and provide the following information:
* A quick summary and/or background.
* Steps to reproduce.
* What you expected would happen.
* What actually happens.
* Notes (possibly including why you think this might be happening, or stuff you tried that didn't work).

### Suggesting Enhancements
Enhancement suggestions are also tracked as GitHub issues. When you are creating an enhancement issue, please include:
* A clear and descriptive title.
* A step-by-step description of the suggested enhancement.
* Explain why this enhancement would be useful to most users.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!

## Code Style
* We follow standard C# coding conventions.
* For the UI, we use WPF-UI guidelines and our DynamicResource dictionary definitions for styling. Please do not hardcode colors!
