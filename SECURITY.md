# Security Policy

## Supported Versions

Currently, only the latest release of DevCleaner Pro is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within DevCleaner Pro, please send an e-mail to jimdev via [jylmdev@gmail.com](mailto:jylmdev@gmail.com). All security vulnerabilities will be promptly addressed.

Please **do not** report security vulnerabilities via public GitHub issues.
